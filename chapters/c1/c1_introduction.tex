\chapter{INTRODUCTION}





\section{Context and Motivation}

Fine-grained visual classification is a specialized task in computer vision that involves identifying sub-categories within a single entry-level category. Unlike general object recognition, which differentiates between disparate classes such as automobiles and landscapes, FGVC requires the model to distinguish between highly similar categories, such as specific bird species, car models, or aircraft variants \cite{TransIFC, HierarchicalFeatureAtt}. Among these, bird image classification is widely regarded as one of the most challenging benchmarks due to the biological complexity and visual similarity inherent in the avian domain \cite{article}. The primary difficulty arises from high intra-class variance, where birds of the same species appear different due to lighting, posture, or life stages, and low inter-class variance, where distinct species share nearly identical plumage patterns and morphology \cite{Zhou_2016_CVPR, TransIFC}.

The challenge becomes more severe when the number of candidate species is large. Given a single bird image, a non-expert observer may not be able to identify the exact species directly because many possible species look similar. However, the recognition process can become easier if the observer can describe a few meaningful visual traits, such as bill shape, wing color, head pattern, breast pattern, tail shape, or crown color. These attributes provide intermediate semantic evidence that can help narrow down candidate species and distinguish visually similar birds, especially species that belong to the same family.

Recent prompt-based and language-assisted fine-grained recognition methods reflect a similar intuition. Instead of relying only on direct class prediction, such methods use visual descriptions, attribute-related prompts, or question-answering procedures to extract discriminative semantic cues before reasoning about fine-grained categories \cite{liu2024democratizing}. This suggests that visual attributes can serve as useful intermediate information between raw image features and fine-grained class decisions.

At the same time, bird recognition is naturally hierarchical. Bird species are organized according to biological taxonomy, where a species belongs to a family and a family belongs to an order. Therefore, a practical bird classification model should not only predict the fine-grained species label, but also produce predictions at higher taxonomic levels such as family and order. Hierarchical prediction is useful because coarse-level categories can organize the search space, while fine-level species prediction requires more detailed visual evidence. However, even when the higher-level family is correctly identified, distinguishing between visually similar species within the same family can remain difficult.

CUB-200-2011 provides a suitable setting for studying this problem because it contains 200 bird species and rich visual attribute annotations describing bird appearance \cite{wah2011cub}. These attributes include part-based and semantic properties such as bill shape, wing color, breast pattern, head pattern, tail shape, and crown color. Since many visually similar bird species differ in such subtle traits, attributes can provide useful semantic supervision for fine-grained hierarchical bird classification.

In this thesis, attributes are not used as manual inputs at inference time. Instead, they are used as auxiliary supervision during training. The central motivation is to investigate whether a model can learn more discriminative species-level representations by using visual attributes as semantic guidance, while still predicting species, family, and order labels from the image alone during inference.

To study this question, this thesis builds upon H-CAST, a recent visually consistent hierarchical classification framework \cite{park2025visually}. H-CAST is selected as the backbone because it provides fine-to-coarse visual representations for hierarchical prediction. The proposed method extends this backbone with attribute-guided learning at the species level, where subtle semantic traits are most useful for distinguishing visually similar species.




\section{Problem Statement}

This thesis addresses the problem of attribute-guided fine-grained hierarchical bird image classification. Given a single bird image, the model must predict labels at multiple taxonomic levels, including order, family, and species. The task is challenging for two main reasons. First, the number of fine-grained species classes is large enough to make direct species recognition challenging. Second, many bird species, especially species from the same family, are visually similar and differ only in small local traits such as bill shape, wing pattern, head pattern, breast color, or tail shape.

Formally, for an input bird image \(x_i\), the model is required to predict a hierarchical label tuple:
\[
    (\hat{y}_i^{o}, \hat{y}_i^{f}, \hat{y}_i^{s}),
\]
where \(\hat{y}_i^{o}\), \(\hat{y}_i^{f}\), and \(\hat{y}_i^{s}\) denote the predicted order, family, and species labels, respectively. Following the CUB-200-2011 hierarchical setting, the taxonomy contains 13 orders, 38 families, and 200 species.

In addition to image labels, CUB-200-2011 provides visual attribute annotations that describe semantic bird traits. This thesis studies how such attribute information can be used during training to guide the learning of discriminative visual representations. The goal is to improve fine-grained species recognition, particularly among visually similar species within the same family, while maintaining accurate and consistent hierarchical predictions.

During inference, the model receives only the input image and does not require manually provided attribute labels. Therefore, the problem is not to classify birds using ground-truth attributes as test-time input, but to learn from attribute supervision during training so that the image-based model becomes better at hierarchical fine-grained recognition.


\section{Research Gap and Research Questions}

Fine-grained hierarchical bird classification remains challenging because the model must predict labels at multiple taxonomic levels while also distinguishing a relatively large number of visually similar species. In CUB-200-2011, many bird species belong to the same family and share highly similar global appearance. Their differences may appear only in small visual traits such as bill shape, wing pattern, head pattern, breast color, tail shape, or crown color. Therefore, image-level class supervision alone may not provide sufficient guidance for learning the subtle semantic evidence needed for species-level discrimination.

Recent prompt-based and language-assisted fine-grained recognition methods suggest that semantic visual traits can serve as useful intermediate evidence when direct category recognition is difficult \cite{liu2024democratizing}. Instead of predicting the fine-grained category directly, such methods often use attribute descriptions, visual questions, or semantic prompts to reason about possible classes. This motivates the question of whether visual attributes can also be useful in a supervised hierarchical bird classification setting.

CUB-200-2011 provides rich visual attribute annotations \cite{wah2011cub}, but it remains unclear how these attributes should be used in a hierarchical image classification model while keeping inference image-only. Directly using ground-truth attributes as test-time input would change the problem setting, because such attributes are not available in normal inference. Therefore, this thesis focuses on using attributes as training-time auxiliary supervision, so that the model learns more discriminative image-based representations without requiring manual attribute labels at inference time.

Another gap concerns attribute selection. Although CUB provides 312 attributes, not all of them are equally useful for distinguishing visually similar species. Some attributes may be common across many species, redundant with other attributes, or weakly related to the most difficult species-level confusions. This is especially important for species within the same family, where useful attributes should help distinguish hard sibling species rather than only describe general bird appearance.

Finally, it is necessary to identify which components actually contribute to the benefit of attribute guidance. Attribute-guided learning may improve performance because of auxiliary semantic supervision, because of species-level feature fusion, because of cross-attention-based attribute feature extraction, or simply because of additional model capacity. Therefore, the thesis evaluates these components through controlled ablation studies, including direct-fusion alternatives and variants without auxiliary attribute supervision.

The internal Sibling-IVAS baseline in this thesis refers to a node-vs-siblings attribute selection method based on positive occurrence rate, negative occurrence rate, and information value.

To address these gaps, this thesis studies the following research questions:

\begin{itemize}
    \item \textbf{RQ1: Overall effectiveness of attribute guidance.}
    Can visual attributes improve fine-grained hierarchical bird classification when they are used as auxiliary supervision during training, while inference remains image-only?

    \item \textbf{RQ2: Role of attribute-guided fusion and semantic supervision.}
    Does the improvement come from species-level feature fusion, auxiliary attribute prediction supervision, or the combination of both?

    \item \textbf{RQ3: Role of cross-attention.}
    Does attribute-query cross-attention provide additional benefit compared with a simpler direct-fusion design that does not use cross-attention?

    \item \textbf{RQ4: Attribute selection strategy.}
    Does Hard-Sibling Discriminative Attribute Selection (HSDAS) provide a more effective attribute subset than using all attributes, equally sized random subsets, or the internal Sibling-IVAS statistical baseline?

    \item \textbf{RQ5: Role of diversity regularization.}
    How does diversity regularization affect species accuracy, Full-Path Accuracy, weighted Average Precision, and taxonomy consistency?

    \item \textbf{RQ6: Error behavior.}
    In which types of prediction errors does the attribute-guided model improve over the image-only hierarchical baseline, and do the improvements mainly occur in intra-family species confusions?
\end{itemize}





\section{Objectives}

The primary objective of this thesis is to develop and evaluate an attribute-guided method for supervised fine-grained hierarchical bird image classification on CUB-200-2011. Specifically, the study aims to:

\begin{itemize}
    \item Use CUB visual attributes as training-time auxiliary semantic supervision while preserving image-only inference.

    \item Organize the 312 CUB visual attributes into semantic groups and formulate attribute prediction as group-wise classification.

    \item Design an attribute-guided species-level feature learning module that uses attribute-oriented representations to support fine-grained species prediction.

    \item Instantiate the proposed attribute-guided approach on top of H-CAST, a visually consistent hierarchical classification backbone.

    \item Compare attribute-query cross-attention with a simpler direct-fusion baseline that does not use cross-attention.

    \item Study attribute usage and selection strategies, including FullAttr-312, Sibling-IVAS-188, HSDAS-174, HSDAS-199, and Random-199.

    \item Analyze the effects of attribute supervision, feature fusion, cross-attention, diversity regularization, and attribute selection on species accuracy, family accuracy, order accuracy, Full-Path Accuracy, weighted Average Precision, TICE, and attribute prediction accuracy.

    \item Conduct prediction-level and diagnostic analyses to understand which types of errors are corrected and to examine how the proposed module changes model behavior.
\end{itemize}






\section{Scope of the Study}

The scope of this research is limited to the CUB-200-2011 dataset. The study focuses on supervised fine-grained hierarchical bird image classification and does not address open-set recognition, zero-shot recognition, or prompt-based inference. Although recent prompt-based and language-assisted methods motivate the usefulness of semantic attributes for fine-grained reasoning, this thesis does not use language prompts, large language models, or manually provided attribute descriptions at inference time. Exploring prompt-based or language-assisted attribute reasoning is left as a possible direction for future work.

The CUB visual attributes are used only during training as auxiliary supervision. In the main setting of this thesis, class-level attribute annotations are used to supervise the group-wise attribute prediction heads. Therefore, all images from the same species share the same class-level attribute target. This setting is useful for injecting species-level semantic priors, but it does not model image-specific attribute visibility caused by pose, occlusion, viewpoint, or background variation.

In addition, attribute localization is outside the scope of this thesis. Any visualization is used only for qualitative diagnosis of model behavior.

The proposed attribute-guided module is applied primarily to the species-level prediction branch, because species recognition requires the most fine-grained visual evidence. Family and order predictions follow the higher-level hierarchical stages of the visual backbone. The main experiments follow the official CUB-200-2011 train/test protocol used in the H-CAST benchmark. Therefore, the conclusions are limited to this dataset and should not be assumed to generalize to other hierarchical classification tasks without further evaluation.




\section{Overview of the Proposed Approach}

This thesis proposes an attribute-guided approach for fine-grained hierarchical bird image classification on CUB-200-2011. The method is implemented on top of H-CAST, a visually consistent hierarchical classification framework. H-CAST is selected as the backbone because it provides fine-to-coarse visual representations through superpixel-based graph grouping, which is suitable for predicting different taxonomy levels such as species, family, and order.

The proposed model preserves the original H-CAST visual parsing pipeline, where image regions are represented by superpixel-based tokens and progressively grouped through graph pooling. This produces hierarchical visual representations at different granularities. The species-level representation is expected to preserve more detailed visual evidence, while higher-level representations are used for family and order prediction.

On top of this image-based hierarchical backbone, the proposed method introduces an attribute-guided module at the species-level branch. This design is motivated by the fact that many species-level confusions occur between visually similar birds within the same family, where subtle traits such as bill shape, wing pattern, head pattern, breast color, or tail shape may be important. Instead of using attributes as additional inputs at inference time, the model uses CUB attributes only as auxiliary supervision during training.

The proposed module organizes selected CUB attributes into semantic groups, such as bill shape, wing color, breast pattern, head pattern, tail shape, and crown color. Each active attribute group is represented by a learnable query. These attribute-group queries attend to the graph-node features from the species-level stage and produce attribute-oriented features. A group-specific classifier predicts the retained attribute category within each active group, providing auxiliary semantic supervision.

The resulting attribute-oriented features are aggregated using an attention-pooling mechanism conditioned on the species class token. The aggregated attribute representation is concatenated with the species-level visual representation and passed through a fusion module before the final species classifier. Family and order predictions are still produced from the original higher-level backbone stages, while the attribute-guided branch primarily aims to improve fine-grained species discrimination.

To evaluate whether attribute-query cross-attention is necessary, this thesis also studies a direct-fusion baseline that removes the cross-attention module. In this baseline, group-wise attribute features are generated directly from the species class token and fused with the species representation. This comparison helps determine whether the proposed cross-attention mechanism provides additional benefit beyond simple feature fusion and auxiliary attribute supervision.

Since not all CUB attributes are equally useful for distinguishing visually similar bird species, this thesis also investigates attribute selection. In particular, Hard-Sibling Discriminative Attribute Selection (HSDAS) selects attributes that help distinguish a species from its sibling species within the same family, with emphasis on hard siblings that have similar attribute profiles. HSDAS is compared with using all attributes, an internal node-vs-siblings statistical selection baseline called Sibling-IVAS, and random attribute subsets.

For the cross-attention-based model, this thesis also evaluates an optional diversity regularization term that encourages attribute-group attention patterns to be less redundant.




\section{Contributions}

The main contributions of this thesis are as follows:

\begin{itemize}
    \item \textbf{Attribute-guided fine-grained hierarchical bird classification.}
    This thesis studies how CUB visual attributes can be used as training-time auxiliary supervision to improve fine-grained hierarchical bird image classification while preserving image-only inference.

    \item \textbf{Group-wise semantic attribute supervision.}
    Instead of treating all 312 CUB attributes as a single flat vector, this thesis organizes attributes into semantic groups and formulates attribute prediction as group-wise classification.

    \item \textbf{Attribute-guided species-level fusion.}
    The proposed model extracts attribute-oriented features from species-level visual representations and fuses the aggregated attribute representation with the species class token before final species classification.

    \item \textbf{Cross-attention and direct-fusion comparison.}
    This thesis evaluates whether attribute-query cross-attention provides additional benefit over a simpler direct-fusion design without cross-attention.

    \item \textbf{Hard-Sibling Discriminative Attribute Selection.}
    This thesis studies HSDAS, an attribute selection strategy that prioritizes attributes useful for distinguishing visually similar sibling species within the same family.

    \item \textbf{Component-wise evaluation and diagnostic analysis.}
    The proposed method is evaluated through main comparison with an image-only hierarchical baseline, fusion and attribute-loss ablations, cross-attention versus direct-fusion comparison, attribute mask comparison, diversity-loss analysis, random attribute controls, prediction-level error analysis, and qualitative diagnostic analysis.
\end{itemize}
