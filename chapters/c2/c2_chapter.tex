\section{Research Gap}

The previous sections show that fine-grained bird classification, attribute-based recognition, and hierarchical image classification have each been studied from different perspectives. Fine-grained visual classification methods focus on learning discriminative visual evidence for subtle category differences. Attribute-based methods use semantic visual properties to describe object appearance and provide additional supervision. Hierarchical classification methods exploit taxonomy structures to produce predictions at multiple semantic levels. However, the integration of these directions remains limited in the context of visually consistent hierarchical bird classification.

First, recent hierarchical classification methods have improved taxonomy-aware prediction by modeling relationships between coarse and fine labels. Methods such as FGN, HRN, TransHP, and H-CAST show that hierarchical information or supervision can improve multi-granularity recognition \cite{chang2021your, Chen_2022_CVPR, wang2023transhp, park2025visually}. Among them, H-CAST is particularly relevant to this thesis because it addresses both visual consistency and semantic consistency. It builds on CAST and uses fine-to-coarse segment grouping so that classifiers at different taxonomy levels are encouraged to rely on coherent image regions \cite{ke2024learning, park2025visually}. Nevertheless, in its CUB setting, H-CAST uses the order-family-species taxonomy but does not explicitly incorporate the rich CUB visual attribute annotations as auxiliary supervision.

Second, CUB-200-2011 provides detailed visual attributes describing bird appearance, including properties related to bill shape, wing color, breast pattern, tail shape, crown color, and other part-based traits \cite{wah2011cub}. These attributes are closely related to the subtle differences that distinguish visually similar bird species. Prior attribute-based recognition studies demonstrate that attributes can serve as semantic descriptions for visual categories and support transferable recognition \cite{farhadi2009attributes, lampert2014attributebased}. Other attribute-guided methods further show that attributes can guide attention or representation learning for localized visual traits \cite{liu2017localizing, han2018attribute, huynh2020DenseAttribute}. However, these methods are not specifically designed to work with a visually consistent hierarchical segmentation model such as H-CAST. As a result, there remains a gap between attribute-guided representation learning and segment-based hierarchical visual parsing.

Third, even when attributes are available, it is unclear whether using all attributes is the best strategy for supervised hierarchical bird classification. CUB contains 312 attributes, but not all of them are equally useful for every classification decision. Some attributes may be redundant, broadly shared across many species, or weakly discriminative for distinguishing sibling species. General feature selection methods provide criteria for selecting informative variables \cite{peng2005feature, kira1992practical, kononenko1994estimating}, but they do not directly address the use of human-interpretable bird attributes inside a hierarchical visual classification model.

More closely related to this thesis, sibling-aware attribute querying has been studied in field-guide-inspired zero-shot learning. Mall et al. propose sibling-aware attribute querying strategies that prioritize attributes useful for distinguishing a class from related classes in a taxonomy, showing that local taxonomic distinctions can be more informative than global attribute variation \cite{mall2021field}. However, their setting focuses on reducing expert annotation cost for zero-shot class descriptions. In contrast, this thesis studies a supervised hierarchical classification setting where class-level CUB attributes are already available during training. The gap addressed here is how to use hard-sibling-aware attribute selection to construct a compact attribute supervision mask for an H-CAST-based hierarchical classifier.

Fourth, when multiple attribute groups are introduced into a visual model, another challenge is how to make their learned representations complementary. If different attribute groups attend to the same visual region, the model may fail to exploit the diverse semantic information provided by attributes. Diversity-based regularization methods in fine-grained classification suggest that encouraging different features to focus on different discriminative regions can reduce redundancy \cite{Chang_2020}. In this thesis, this idea is adapted from channel-level feature diversity to attribute-group attention diversity in an H-CAST-based model.

Motivated by these gaps, this thesis investigates attribute-guided feature learning for hierarchical bird image classification. The proposed approach extends the image-only H-CAST framework by adding attribute-group supervision and species-level attribute-guided fusion. It also studies Hard-Sibling Discriminative Attribute Selection (HSDAS), which adapts the intuition of sibling-aware attribute selection to supervised H-CAST-based bird classification. Rather than claiming sibling-aware attribute selection as a completely new idea, this thesis focuses on integrating hard-sibling-aware attribute selection with attribute-guided representation learning in a visually consistent hierarchical classifier. Through comparisons with FullAttr-312, Sibling-IVAS-188, and Random-199, this thesis evaluates whether a compact, hard-sibling-aware attribute subset can better support fine-grained species recognition and hierarchical consistency on CUB-200-2011 than using all attributes, equally sized random subsets, or the internal Sibling-IVAS statistical baseline.
