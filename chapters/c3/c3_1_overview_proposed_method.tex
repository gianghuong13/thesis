\section{Overview of the Proposed Method}


This thesis proposes an attribute-guided extension of H-CAST for hierarchical bird image classification on CUB-200-2011. The original H-CAST framework performs hierarchical image classification by combining segment-based visual grouping with multi-level supervision \cite{park2025visually}. It processes an input image through a fine-to-coarse visual hierarchy and predicts labels at different taxonomic levels, such as species, family, and order. However, in its CUB setting, H-CAST uses the order-family-species taxonomy but does not explicitly incorporate the rich visual attribute annotations provided by CUB-200-2011 as auxiliary supervision. The proposed method addresses this limitation by integrating attribute-based supervision and attribute-guided species-level feature fusion into the H-CAST pipeline.

Figure~\ref{fig:proposed_overview} illustrates the overall architecture of the proposed method. Given an input bird image, the H-CAST backbone first extracts hierarchical visual representations using superpixel-based segment tokens and graph pooling, following CAST and H-CAST \cite{ke2024learning, park2025visually}. These representations are used to produce predictions at different taxonomy levels. In the original H-CAST design, the species, family, and order classifiers are attached to different stages of the visual hierarchy. In the proposed model, this hierarchical structure is preserved. The family and order predictions are still produced from the corresponding higher-level H-CAST stages, while the species-level branch is enhanced with attribute-guided learning.

The main addition of this thesis is an attribute-guided module attached to the species-level branch. This design is motivated by the nature of fine-grained bird classification. Species-level recognition often depends on subtle and localized visual traits, such as bill shape, crown color, wing pattern, breast markings, or tail shape. These traits are directly described by CUB attributes \cite{wah2011cub}. Therefore, instead of relying only on species labels, the proposed model uses attribute annotations as auxiliary supervision to encourage the learned representation to encode fine-grained bird characteristics.

The attribute-guided module operates at the level of attribute groups rather than individual binary attributes. In this thesis, the 312 CUB attributes are organized into semantic groups based on their attribute names, such as bill shape, wing color, head pattern, breast color, and tail shape. For each active attribute group, the model maintains a learnable attribute-group query. These queries attend to the graph-node features from the species-level stage of H-CAST and extract attribute-oriented visual representations. Each attribute-oriented representation is then passed to a group-specific classifier, which predicts the retained attribute category within that group. These attribute predictions are used as auxiliary outputs during training.

In addition to auxiliary attribute prediction, the proposed model uses the learned attribute-oriented features to improve species classification. The attribute features are aggregated through an attention-pooling mechanism conditioned on the species-level visual representation. The resulting attribute summary is concatenated with the species class token and passed through a fusion module before the final species classifier. In this way, the species prediction is guided not only by the image representation learned by H-CAST, but also by attribute-oriented features that capture discriminative bird traits.

An important design choice is that the attribute-guided fusion is applied primarily to the species-level branch. This is consistent with the role of attributes in fine-grained recognition: attributes are expected to be most useful for distinguishing visually similar species, while family and order labels correspond to coarser taxonomic levels. Therefore, the proposed model preserves the original H-CAST predictions for family and order, and introduces attribute-guided fusion only for species prediction. Although family and order classifiers are not directly fused with attribute features, they are still trained jointly with the species branch in the hierarchical classification framework.

Since CUB provides 312 attributes, using all attributes may introduce redundancy or weakly useful supervision. To address this issue, this thesis studies several attribute selection strategies. The proposed strategy, Hard-Sibling Discriminative Attribute Selection (HSDAS), selects attributes that help distinguish a taxonomic node from its sibling nodes, especially hard siblings with similar attribute profiles. The selected attributes define the active attribute groups used by the attribute prediction heads and the attribute-guided fusion module. This allows the model to focus on a compact subset of attributes that are more relevant to fine-grained hierarchical discrimination.

The model is trained with a combination of level-wise hierarchical classification loss, Tree-Path KL divergence for semantic consistency, attribute prediction loss, and an optional attribute attention diversity loss. The hierarchical classification loss follows the H-CAST setting and supervises predictions at species, family, and order levels. The attribute prediction loss supervises the group-specific attribute heads using the selected attribute labels. The diversity loss is inspired by the diversity component of Mutual-Channel Loss \cite{Chang_2020}, but is adapted to attribute-group attention maps. Its purpose is to encourage different attribute groups to attend to complementary visual regions instead of collapsing onto the same image evidence.

During inference, the model remains image-based. No manually provided attribute labels are required. Given an input image, the H-CAST backbone extracts hierarchical visual features, the attribute-group queries produce internal attribute-oriented representations, and the fused species representation is used for species prediction. The model also outputs family and order predictions from the original H-CAST hierarchy. Thus, attributes are used to guide representation learning during training, while the final prediction pipeline remains compatible with standard image-only classification.

Overall, the proposed method combines three components: a visually consistent H-CAST backbone, attribute-guided species-level feature learning, and hard-sibling-aware attribute selection. The goal is to improve fine-grained species discrimination while preserving hierarchical prediction across species, family, and order. This design directly addresses the research gap identified in Chapter 2: H-CAST provides a strong image-only hierarchical classifier, while CUB attributes provide semantic cues that can guide the model toward discriminative bird traits.
