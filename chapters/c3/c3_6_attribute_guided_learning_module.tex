\section{Attribute-Guided Learning Module}

This section describes the attribute-guided learning module added on top of the H-CAST backbone \cite{park2025visually}. The purpose of this module is to use CUB attribute annotations \cite{wah2011cub} as auxiliary semantic supervision and to inject attribute-oriented information into species-level prediction. The module is designed for the species branch because species recognition is the most fine-grained level of the task and is expected to benefit most from semantic traits such as bill shape, wing pattern, breast color, crown color, and tail shape.

The proposed module has four main components: attribute-group queries, cross-attention over species-level graph features, group-specific attribute prediction heads, and species-level attribute fusion. Importantly, the module does not use one query or one classifier for each individual CUB attribute. Instead, it operates at the level of active attribute groups. Each active group corresponds to a semantic trait type, such as \textit{bill shape}, \textit{wing color}, \textit{breast pattern}, or \textit{tail shape}.

\subsection{Attribute-Group Queries}

Let the set of active attribute groups be denoted as
\begin{equation}
    \mathcal{G}_{active}
    =
    \{g_1, g_2, \ldots, g_G\},
\end{equation}
where \(G\) is the number of active groups after applying the attribute mask. For the FullAttr-312 setting, \(G=28\). For selected attribute subsets, groups with no retained attributes are removed.

The model maintains one learnable query for each active attribute group. Let the learnable attribute-query matrix be
\begin{equation}
    Q^{a}
    =
    [\mathbf{q}_{g_1}, \mathbf{q}_{g_2}, \ldots, \mathbf{q}_{g_G}]
    \in \mathbb{R}^{G \times D},
\end{equation}
where \(D\) is the hidden dimension of the H-CAST backbone. Each query \(\mathbf{q}_{g}\) is associated with one semantic attribute group \(g\), not with one individual attribute. Therefore, the number of attribute queries is equal to the number of active attribute groups, rather than the total number of selected attributes.

For a mini-batch of size \(B\), the query matrix is expanded to
\begin{equation}
    Q^{a}_{B}
    \in
    \mathbb{R}^{B \times G \times D}.
\end{equation}
Before being used in attention, the queries are normalized with layer normalization to align their scale with the H-CAST feature representations.

\subsection{Cross-Attention over Species-Level Graph Features}

The attribute queries attend to graph-node features from the species-level stage of H-CAST. Let
\begin{equation}
    H^{s}
    \in
    \mathbb{R}^{B \times N_s \times D}
\end{equation}
denote the species-level graph-node features, where \(N_s\) is the number of graph nodes at the species-level stage. Let
\begin{equation}
    \mathbf{c}^{s}
    \in
    \mathbb{R}^{B \times D}
\end{equation}
denote the species-level class token.

For the CUB three-level hierarchy, the attribute-guided module uses graph-node features from the species-level stage. In the implementation, this corresponds to the graph nodes from the second H-CAST block and the corresponding species class token. Family and order predictions are produced from later and coarser H-CAST stages.

The cross-attention operation uses attribute-group queries as queries, and species-level graph-node features as keys and values:
\begin{equation}
    H^{a}
    =
    \mathrm{MHA}
    \left(
        Q^{a}_{B},
        H^{s},
        H^{s}
    \right),
\end{equation}
where \(\mathrm{MHA}(\cdot)\) denotes multi-head attention \cite{vaswani2017attention}. The output is
\begin{equation}
    H^{a}
    =
    [\mathbf{h}^{a}_{g_1}, \mathbf{h}^{a}_{g_2}, \ldots, \mathbf{h}^{a}_{g_G}]
    \in
    \mathbb{R}^{B \times G \times D}.
\end{equation}
Each vector \(\mathbf{h}^{a}_{g}\) is an attribute-oriented representation for group \(g\).

This operation allows each attribute group to extract an internal representation from the species-level graph nodes. However, the model is not trained with pixel-level or part-level attribute localization labels. Therefore, the attention weights should be interpreted as internal diagnostic signals rather than guaranteed localization maps of semantic attributes. This distinction is especially important for global groups such as \textit{size} and \textit{shape}, which do not correspond to one specific localized bird part.

A key-padding mask is used in the attention operation to ignore invalid graph nodes introduced by padding. After cross-attention, the attribute-oriented features are normalized and passed through dropout:
\begin{equation}
    H^{a}
    =
    \mathrm{Dropout}
    \left(
        \mathrm{LN}(H^{a})
    \right).
\end{equation}

\subsection{Group-Specific Attribute Prediction}

The attribute-oriented features are supervised by group-specific attribute prediction heads. For each active group \(g \in \mathcal{G}_{active}\), the model defines a separate linear classifier:
\begin{equation}
    f_g^{a}: \mathbb{R}^{D} \rightarrow \mathbb{R}^{C_g},
\end{equation}
where \(C_g\) is the number of retained attribute states in group \(g\). The classifier for group \(g\) receives the corresponding attribute-oriented feature \(\mathbf{h}^{a}_{g}\) and produces logits:
\begin{equation}
    \mathbf{z}^{a}_{g}
    =
    f_g^{a}
    \left(
        \mathrm{LN}(\mathbf{h}^{a}_{g})
    \right).
\end{equation}

This design means that the model does not predict a single 312-dimensional binary attribute vector. Instead, it predicts one retained attribute category for each active attribute group. For example, the classifier for \textit{bill shape} predicts among the retained bill-shape states, while the classifier for \textit{wing color} predicts among the retained wing-color states.

The group-specific attribute predictions are used only as auxiliary outputs during training. Let \(\tilde{t}_{i,g}\) be the remapped target label for sample \(i\) and group \(g\). Let \(\Omega_g\) denote the set of samples whose remapped target for group \(g\) is valid, i.e., not ignored by the selected mask. The set of valid groups in a mini-batch is
\begin{equation}
    \mathcal{G}_{valid}
    =
    \{g \in \mathcal{G}_{active} \mid |\Omega_g| > 0\}.
\end{equation}
The attribute prediction loss is computed as
\begin{equation}
    \mathcal{L}_{attr}
    =
    \frac{1}{|\mathcal{G}_{valid}|}
    \sum_{g \in \mathcal{G}_{valid}}
    \frac{1}{|\Omega_g|}
    \sum_{i \in \Omega_g}
    \mathcal{L}_{CE}
    \left(
        \mathbf{z}^{a}_{i,g},
        \tilde{t}_{i,g}
    \right).
\end{equation}

The role of this auxiliary attribute loss is to encourage the attribute-guided branch to encode information related to semantic bird traits. These attribute predictions are not used as discrete inputs for species classification. Instead, the continuous attribute-oriented features are used in the fusion stage.

\subsection{Species-Level Attribute Fusion}

After obtaining the attribute-oriented features \(H^{a}\), the model aggregates them into a single attribute summary vector. This is done using attention pooling conditioned on the species-level class token. The species class token is used as the query, while the attribute-oriented features are used as keys and values:
\begin{equation}
 \tilde{\mathbf{h}}^{a}_{sum}
=
\mathrm{MHA}
\left(
    \mathbf{c}^{s}_{1},
    H^{a},
    H^{a}
\right),
\qquad
\mathbf{c}^{s}_{1} \in \mathbb{R}^{B \times 1 \times D},
\end{equation}
where \(\mathbf{c}^{s}_{1}\) is the species class token with an added sequence dimension. The output is squeezed to obtain
\begin{equation}
    \mathbf{h}^{a}_{sum}
    \in
    \mathbb{R}^{B \times D}.
\end{equation}

This attention-pooling step allows the species-level visual representation to select and combine useful attribute-group features. Instead of treating all attribute groups equally, the model can assign different importance to different attribute-oriented representations depending on the input image.

The resulting attribute summary is concatenated with the species-level class token:
\begin{equation}
    \mathbf{h}^{fuse}_{in}
    =
    [
        \mathbf{c}^{s};
        \mathbf{h}^{a}_{sum}
    ]
    \in
    \mathbb{R}^{B \times 2D}.
\end{equation}

The concatenated vector is then passed through a fusion multilayer perceptron:
\begin{equation}
    \mathbf{h}^{s}_{fused}
    =
    \mathrm{MLP}_{fuse}
    \left(
        \mathbf{h}^{fuse}_{in}
    \right),
\end{equation}
where the fusion module maps the \(2D\)-dimensional concatenated representation back to the original hidden dimension \(D\). In the implementation, this fusion module consists of a linear layer, a GELU activation, and layer normalization.

The final species classifier uses the fused species representation:
\begin{equation}
    \mathbf{z}^{s}
    =
    f_s
    \left(
        \mathbf{h}^{s}_{fused}
    \right).
\end{equation}

The attribute-guided fusion is applied to the species-level branch. Family and order predictions are still produced from the original H-CAST hierarchical stages. In the three-level CUB setting, the family classifier uses the family-level H-CAST class token, and the order classifier uses the coarser order-level H-CAST class token:
\begin{equation}
    \mathbf{z}^{f}
    =
    f_f(\mathbf{c}^{f}),
    \qquad
    \mathbf{z}^{o}
    =
    f_o(\mathbf{c}^{o}).
\end{equation}

Therefore, attributes do not directly modify the family or order classifiers. Their primary effect is on species-level classification, where fine-grained semantic traits are expected to be most useful. Family and order predictions may still be indirectly affected during training because the whole network is optimized jointly, but there is no direct attribute fusion into those branches.

\subsection{Direct-Fusion Baseline without Cross-Attention}

To evaluate whether attribute-query cross-attention is necessary, this thesis also considers a direct-fusion baseline without cross-attention. This baseline keeps the same image-only inference setting and the same group-wise attribute supervision, but removes the cross-attention operation between attribute-group queries and species-level graph nodes.

Instead of computing \(H^{a}\) through cross-attention, the direct-fusion baseline generates group-wise attribute features directly from the species class token:
\begin{equation}
    H^{a}_{direct}
    =
    \mathrm{reshape}
    \left(
        \mathrm{MLP}_{direct}(\mathbf{c}^{s})
    \right)
    \in
    \mathbb{R}^{B \times G \times D}.
\end{equation}
These direct attribute features are passed to the same group-specific attribute classifiers and are aggregated for species-level fusion. In the implemented baseline, the attribute summary can be obtained by averaging the group-wise features:
\begin{equation}
    \mathbf{h}^{a}_{sum}
    =
    \frac{1}{G}
    \sum_{g \in \mathcal{G}_{active}}
    \mathbf{h}^{a}_{g}.
\end{equation}

This baseline is used as a controlled comparison. If the full cross-attention model outperforms direct fusion, this suggests that extracting attribute-oriented information from species-level graph nodes provides additional benefit. If direct fusion performs similarly, then the improvement may come mainly from auxiliary attribute supervision, species-level fusion, or additional model capacity rather than from cross-attention itself.

Because the direct-fusion baseline does not produce attribute-query spatial attention over graph nodes, the attribute attention diversity loss is not applied to this baseline.

\subsection{Interpretation of Attention Signals}

The cross-attention-based model produces attention weights from attribute-group queries to species-level graph nodes, and attention-pooling weights from the species class token to attribute-group features. These signals can be visualized for diagnostic analysis. However, they should not be interpreted as ground-truth attribute localization.

There are two reasons for this. First, the CUB attributes used in this thesis are class-level attributes rather than image-specific attribute visibility annotations. Second, the model is trained for hierarchical classification and auxiliary attribute prediction, not for pixel-level or part-level localization. Therefore, attention visualization is used only to understand internal model behavior, while the main evidence for effectiveness comes from quantitative metrics, component ablations, and prediction-level case analysis.

\subsection{Summary}

The attribute-guided learning module extends H-CAST by adding attribute-oriented supervision and species-level fusion. The main cross-attention version uses one learnable query for each active attribute group, applies cross-attention over species-level graph-node features, predicts retained attribute categories with group-specific classifiers, and fuses the attention-pooled attribute summary with the species class token. This design allows the model to exploit CUB attributes during training while keeping inference image-based.

This thesis also evaluates a direct-fusion baseline without cross-attention to separate the effects of attribute supervision, feature fusion, cross-attention, and model capacity. At test time, no manually provided attribute labels are required; the attribute-guided module operates internally using only image-derived H-CAST features.
